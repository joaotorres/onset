## Pending decisions

Equal versions render, so a reordered pair of join broadcasts lets the older roster win until the next broadcast. Ticket 34's request said "Screens must never fall back to an older game state", and SPEC §7 says the players' version covers "a lockout or a join", but only for `#scoreboard` and `#controller_status` (that player's own row). Narrower than asked, outside the ticket's criteria. Recommended: close it now, since the fix is the same stamp the scoreboard already uses, one line per partial plus a sentence in §7, and a later fix costs the same but ships a known hole. Alternative: accept it, two joins within the same reorder window is rare and the next broadcast corrects the roster. Ready to type:
